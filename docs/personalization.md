## Local import

The reviewed manifest lives in `src/content/personalized-projects.ts`. The import uses the draft and publication helpers and accepts only `portfolio_personalization_dev` on loopback. Existing rows with differences are reported for review. The development-only example retirement option unpublishes the known demo slugs and preserves their drafts.

Set `PERSONALIZATION_DATABASE_URL` in Git-ignored `.env.personalization` to the dedicated local database. Apply the existing migrations to that database using `DATABASE_URL` and `DATABASE_MIGRATION_URL` for the same target. Then run:

```sh
corepack pnpm db:personalize --plan
corepack pnpm db:personalize --draft
corepack pnpm db:personalize --publish --retire-examples
```

For the local preview, start the site with `DATABASE_URL` pointing at the same dedicated database. The existing demo seed and production deployment workflow are separate. The import does not accept a production database.
