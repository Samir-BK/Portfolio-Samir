# Development roadmap

The portfolio is public and open to visitors without signing in or registering. The owner maintains content through Codex, Git, and local tools. Visitor and admin authentication, user accounts, sessions, OAuth, an admin dashboard, and admin audit logging are outside scope.

Milestones 1–5 are complete. Advance one milestone at a time with the owner’s approval. Keep development, testing, and staging separate from production and record verification results with each milestone.
