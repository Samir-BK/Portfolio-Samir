# Development roadmap

The portfolio is public and open to visitors without signing in or registering. The owner maintains content through Codex, Git, and local tools. Visitor and admin authentication, user accounts, sessions, OAuth, an admin dashboard, and admin audit logging are outside scope.

Milestones 1–4 are complete. Advance one milestone at a time with the owner’s approval. Keep development, testing, and staging separate from production and record verification results with each milestone.

| Milestone                       | Deliverable                                                                                                                                                                                                                     | Acceptance checks                                                                                                                                                                                                                                                                                                        | Depends on                                            |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------- |

Pin Node and one package manager.                                                                                                           | A clean checkout installs from its lockfile. Lint, type checks and a production build pass. The shell works at 360 px and desktop sizes with visible keyboard focus.                                                                                                                                                     | Approval to start implementation                      |

Use fixture content.                                                                                         | Keyboard users can open and close the mobile menu and regain focus. Critical text and links work without client JavaScript.                                                    | 1                                                     |
| 3. Public HTML includes the expected title, heading and canonical URL.                                                                                                                                  | 1                                                     |

Verify the site remains usable with the assistant disabled.                                                                                                   | 6 and approval of provider, budget, and data handling |

The public site can launch at Milestone 6. The assistant can follow as a separate release. For Milestone 5, collect approved copy, project links and media, résumé, and public contact details before editing content.
